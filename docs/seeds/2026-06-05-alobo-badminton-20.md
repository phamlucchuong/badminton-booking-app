# ALOBO badminton venue seed mapping (20 venues)

This document maps 20 badminton venues into the BadBook backend seed script.

Global normalization rules:
- `latitude` and `longitude` are mocked approximate coordinates when the public source did not expose explicit coordinates.
- `license_id`, `bank_*`, owner `users`, and owner emails are generated mock values for development use.
- `price_per_hour` is normalized to one representative value because the schema stores one price per court while many sources publish ranges.
- `24/7`, `24/24`, or `24:00` schedules are normalized to `00:00-23:30` or `23:30` close time because the current schema only supports same-day `open_time` and `close_time`.
- All seeded venue-manager accounts reuse the existing local admin BCrypt hash for password `Admin@123456`; this seed is for development/demo only.
